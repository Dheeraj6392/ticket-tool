### Create a new Angular project without standalone setup
```bash
ng new <project-name> --no-standalone
```

### Example: Create a new Angular project named "Test"
```bash
ng new Test --no-standalone
```

### Add Bootstrap dependency to an Angular project
```bash
ng add @bootstrap/ng-bootstrap
```

### Add Font Awesome dependency to an Angular project
```bash
ng add @fontawesome/angular-fontawesome
```
